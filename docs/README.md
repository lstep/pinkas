# Mostdoc Documentation

This directory contains living documentation for the Mostdoc codebase.

| Document | Purpose |
|----------|---------|
| [ARCHITECTURE.md](./ARCHITECTURE.md) | System architecture, components, data model, tech stack, design decisions |

## Keeping docs up to date

- Update `SETUP.md` when build/run steps change
